# Workforce Management AI – UI Prototype

This folder contains the source code for the clickable Workforce Management AI UI prototype.

## Files
- `index.html` – complete prototype source (HTML, Tailwind CDN configuration, CSS theme tokens, JavaScript interactions).

## Run locally
1. Extract this folder.
2. Open `index.html` in Chrome or another modern browser.

Internet access is required for the Tailwind CDN, Google Fonts (Montserrat), and Lucide icon CDN.

## Included
- Responsive sidebar navigation
- Workforce overview dashboard
- AI assistant prototype screen
- Employee, attendance, shift, production, analytics, recommendations and approvals navigation screens
- Light/dark theme toggle
- Official workforce brand palette
- Empty states instead of fabricated workforce data

## Important
This is a static UI prototype, not a React/Vite application yet. It does not connect to FastAPI, Neon PostgreSQL, Domo, or an AI agent.
